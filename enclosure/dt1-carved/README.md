## 自己改尺寸 / 重新生成

使用 **Blender 5.2.2 LTS**（已实测），不需要另外安装 Python 包。在仓库根目录运行：

```sh
blender -b --factory-startup --python enclosure/build_dt1.py -- --variant carved --check --blend --out /tmp/hark-dt1-build
```

两个 STL 在 `/tmp/hark-dt1-build/dt1-carved/parts/`，同级还有装配状态的 `.blend` 和安全检查结果 `checks.json`。省略 `--blend` 就只输出 STL 和检查结果；省略 `--out` 会新建临时目录并打印位置。脚本拒绝覆盖仓库里的两款成品目录。

主要参数在 [`../build_dt1.py`](../build_dt1.py) 开头：`PACK_*` 是实测包装尺寸 20.5 × 24.5 × 11.0 mm，`FIT_*` 是各方向总余量；内腔长先扣掉 USB 伸出量。壁厚、孔位、卡扣和挡块与简易款共用。`*_KNOTS` 控制兽面曲线的节点、切线和线宽，`ENGRAVE_SHALLOW` / `ENGRAVE_DEEP` 控制两档刻深。孔位、挡块和图案不会随内腔等比缩放，换板后要分别调整。

`--check` 要求量化到 0.001 mm 后，每个三角面都与仓库现有 STL 相同；差异会打印 `DIFFERENT` 并返回失败。改尺寸或图案后应去掉 `--check`，几何安全检查仍会运行：结构壁厚、刻纹线宽与留筋下限 0.8 mm，距倒角起点至少 0.6 mm，中心线曲率半径大于最大半线宽加 0.01 mm；还会检查最终刻深和首层接触面积。留筋检查是保守采样，包含连续转弯和明确接点的排除区，不代表整件强度证明。原绳孔只记录留筋，不另加 2 mm 限制。

其他 Blender 版本可能改变布尔运算和三角化结果，先用默认参数跑 `--check` 确认。把 `carved` 换成 `all` 可以一次生成两款。改完仍需实物试装。
